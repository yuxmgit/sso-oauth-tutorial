# SSO 与 OAuth 从 0 到精通

> 一套"**文档教程为主线 + 可运行 Demo 为辅助**"的单点登录（SSO）与第三方授权（OAuth）学习体系。
> 零依赖、零数据库，所有 Demo 只需 Node.js（>= 18），`npm start` 即可运行。

---

## 一、为什么学这个？

想象你每天上班的情景：

- 早上打开 **公司邮箱**，输了一遍密码；
- 打开 **OA 审批系统**，又输了一遍密码；
- 打开 **Wiki**、打开 **Jira**……每个系统都要登录一遍。

你会想：**"我明明已经登录过了，为什么不能一次登录、处处通行？"**

这就是 **SSO（Single Sign-On，单点登录）** 要解决的问题。

再想象另一个情景：

- 你在一个陌生网站想下载资料，它却让你"用微信登录"或"用 GitHub 登录"。
- 你从来没在这个网站注册过，却 3 秒钟就登录成功了。

这就是 **OAuth（第三方授权登录）** 要解决的问题。

本教程将带你从"为什么会诞生这些技术"讲起，一步步亲手把它们**从零写出来**。

## 三、环境准备

1. 安装 **Node.js >= 18**（建议 LTS 版本），验证：

```powershell
node -v
# 输出类似 v20.x.x 即可
```

2. 本项目所有 Demo **零第三方依赖**（只用 Node 内置模块 `http`、`crypto` 等），
   不需要 `npm install`，直接启动：

```powershell
cd I:\work-body-dir\sso-oauth-tutorial\demos\01-basic-session
npm start
```

3. 浏览器访问对应地址（每个 Demo 的文档中都有详细操作步骤）。

## 四、怎么学效果最好？

1. **先读文档，再跑 Demo**：每章文档开头用生活化类比讲"为什么"，中间讲原理，结尾有"动手实验"环节。
2. **别只复制粘贴**：Demo 代码都加了详细中文注释，建议打开源码对照文档逐行看。
3. **做破坏性实验**：比如手动改 Cookie、改 JWT 里的内容，观察系统如何反应——这是理解安全机制最快的方式。
4. **画流程图**：读完每章尝试自己默画时序图，画不出来就回去重读。

## 五、统一设定（贯穿全教程的角色）

为了降低跨章节的理解成本，全部教程使用同一套角色设定：

- **Bob**：用户（打工人，你我他）
- **App A / App B**：Bob 要使用的业务系统（如 OA、Wiki）
- **AuthServer（认证中心）**：负责"发证"的一方
- **Client（客户端）**：接入登录的一方
- **Resource Server（资源服务器）**：存数据的一方（如用户资料 API）
- **Eve（攻击者）**：安全攻防章节的反派
